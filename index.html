Clear limits, before surprises

What “preserve” really means.

ClipTurn is designed to protect the file, not oversell the result. These are the important boundaries to know before you rotate.

1

Compressed video is re-encoded

The default aims for a visually lossless result in the source codec when a compatible encoder exists. Repeated rotations can accumulate loss.

2

Exact means uncompressed AVI

Only supported uncompressed packed-pixel AVI can be rotated sample-exactly, without a decoder or encoder.

3

Successful Explorer turns replace the file

There is no persistent Explorer backup and no undo after success. In-app backup is optional and off by default.

4

Some codecs depend on Windows

VP9, HEVC, Media Feature Pack, hardware, and driver availability can determine what a particular PC can rotate.

The practical questions

Before you make the turn.

Is ClipTurn free?

Yes. ClipTurn is currently free through Microsoft Store. See pricing and everything included.

Does ClipTurn rotate every video losslessly?

No. Supported uncompressed AVI can be rotated sample-exactly. Compressed video is physically rotated through a visually lossless re-encode under the default policy, so repeated turns can accumulate loss.

Does it keep my original file?

A successful rotation replaces the selected file in place. File Explorer rotations keep no persistent backup and cannot be undone. When rotating inside the app, an optional backup setting is available and is off by default. If ClipTurn refuses or fails before a safe commit, the source remains unchanged.

Will the rotated file be the same size?

Not necessarily. ClipTurn does not lower quality merely to force the output back to the source byte size, so a faithful result can be somewhat larger.

Why can a supported format still be refused?

The container name is only one part of the file. Codec, bit depth, track layout, metadata, installed Windows codecs, and hardware can all affect whether ClipTurn can produce and prove a faithful result. When it cannot, it gives a specific reason instead of taking a risky guess.
