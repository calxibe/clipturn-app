Before you start

The one thing worth knowing first

There are two completely different ways to rotate a video, and most of the confusion online comes from tools that never say which one they used.

Approach What changes The catch
A display flag A single orientation value in the file header. The stored picture is untouched, so it is instant and lossless. Only works in MP4, M4V and MOV, and any player, editor or website that ignores the flag still shows the video sideways.
Physical rotation The stored picture itself is turned, so the new orientation travels with the file everywhere. Compressed video has to be decoded and encoded again, which costs time and one generation of quality.

Neither is universally right. A display flag is the better answer when you only need the video to look correct in a modern player and you refuse to lose any quality. Physical rotation is the better answer when the file is going somewhere you do not control — an older editor, a projector, a submission portal, a television. The MP4 guide works through the choice in detail.

Keep a copy of anything irreplaceable.

Rotating a video means writing a new file. Whatever tool you use — ClipTurn included — make an independent copy of footage you cannot film again before you start.
