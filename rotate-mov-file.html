How to rotate a MOV file on Windows

MOV is what an iPhone hands you, and it lands on a Windows PC carrying more than just a picture: a capture date, GPS coordinates, camera details, and sometimes a rotation flag that Windows and the phone disagree about. This covers turning the clip the right way up without QuickTime, keeping everything else intact, and the two cases where a MOV is deliberately refused rather than quietly broken.

First, the myth

You do not need QuickTime

Advice to install QuickTime for Windows is still everywhere, and it is out of date by about a decade.

Apple discontinued QuickTime for Windows in 2016 and stopped shipping security updates for it. Modern Windows plays MOV files perfectly well without it, and any current rotation tool reads and writes the container directly. Installing it today adds unpatched software to your PC and buys nothing.

MOV and MP4 are closer than they look.

Both descend from the same container design, which is why a tool that handles MP4 usually handles MOV and M4V through the same route. ClipTurn treats .mp4, .m4v and .mov as one family with the same rules and the same limits.

The method

Rotate a MOV on Windows

  1. Get the file onto a local drive

    Copy it off the phone, the memory card or the network share first. Removable, network and non-NTFS storage is refused, because the guarantees needed to replace a file safely and recover from an interruption are not available there. A OneDrive file works if it is fully downloaded rather than a placeholder.

  2. Install ClipTurn and open it once

    Free from Microsoft Store, no account needed. Opening it once registers its File Explorer commands.

  3. Right-click and choose a direction

    Open ClipTurn – Video Rotator and pick Rotate video left or Rotate video right. This turns the stored picture, so the result is correct in every player rather than only the ones that read a flag.

  4. Confirm it held

    Open the file somewhere other than the app you fixed it in, and check Properties → Details: after a genuine quarter turn a 1920×1080 clip reads 1080×1920.

The rotation replaces the original.

It is verified before anything is overwritten, but there is no undo. For footage you cannot film again, copy it first — or use Open in ClipTurn from the same menu and switch on Create a backup before replacement in Settings.

The other route

The lossless option for MOV

MOV is one of the three containers — with MP4 and M4V — that carries an orientation instruction in its header. Rewriting that instead of the picture costs nothing at all: no decoding, no encoding, not a single pixel touched.

  • Instant, and completely lossless.
  • Ignored by anything that ignored the original flag — older editors, some projectors and televisions, and conversion pipelines that re-encode on upload.
  • Offered as a reviewed rotated copy when exact replacement is not possible: the changes are listed before anything starts, the copy is saved under a new name, and the original is never replaced without approval.

Use it when the clip stays on modern software you control. Use physical rotation when it is going somewhere you do not. The MP4 guide compares the two properly.

The part that matters later

What survives the rotation

A MOV off a phone is half metadata. Losing it is the difference between a photo library that still sorts correctly in five years and one that does not.

Carried through Why it matters
Capture and media-created time The date Explorer and photo apps sort by. Converters that stamp today's date scramble a whole library.
GPS coordinates Where the clip was filmed, used by map views in photo software.
Camera make and model Movie-level identity metadata, kept with the rest.
Audio, exactly The soundtrack is copied as original packets and verified, never re-encoded to hide a problem.
Colour and HDR declarations An HDR clip that loses these comes back looking washed out.
Track language and display geometry Checked against the source before the result is allowed to replace anything.
One documented exception.

Ordinary iPhone timecode and sensor metadata tracks can be dropped, and when that happens it is stated explicitly in the result rather than passing unmentioned. Everything ClipTurn cannot carry is either disclosed or refused.

The usual iPhone snag

iPhone clips and HEVC

Recent iPhones record HEVC by default, and Windows does not always include an HEVC encoder even when it can happily play the file. That combination plays your holiday footage perfectly and cannot write it back out.

  • Install a compatible HEVC Video Extensions package from Microsoft Store when the app offers the link. The Microsoft package can be separately priced.
  • An eligible 8-bit HEVC clip can instead fall back to H.264, and the result names that fallback rather than applying it silently.
  • A 10-bit HEVC source never falls back to 8-bit. If no Main10 encoder is available it refuses instead, because quietly halving the bit depth of HDR footage is not a fix.
  • Main10 encoding usually depends on your graphics driver. Installing the current driver from your PC or GPU manufacturer and re-running the capability analysis is the fix that actually works.

Setting the phone to record in Most Compatible rather than High Efficiency avoids the whole issue for future clips, at the cost of larger files.

Deliberate limits

Two MOV files that are refused

A Live Photo MOV

A Live Photo is a still image paired with a short MOV. Rotating the video on its own would leave the pair mismatched, so it is refused and the source is left untouched. That is a deliberate choice, not a gap: producing a video that no longer matches its photo would be worse than doing nothing.

A MOV with extra tracks or unusual geometry

The MP4-family route carries one video track and at most one audio track. These refuse rather than being silently stripped:

  • A second video or audio track, subtitles, or chapters.
  • Fragmented files, and non-square or fractional display geometry.
  • Field-coded or interlaced H.264.
  • Dolby Vision enhancement metadata, which cannot survive this path. Where an eligible base HDR layer can be kept, the result names what was dropped.

In most of those cases a reviewed rotated copy is still offered, so you get an explicit choice rather than a dead end. The troubleshooting guide covers every cause, and the tested-formats matrix shows the real outcome for 99 actual files.

More than one

A camera roll's worth

Sideways MOV files rarely arrive alone. Select them all in File Explorer and rotate once — the direction applies to each file independently — or drop the folder onto ClipTurn's Batch Rotate tab, where every clip keeps its own status and reason. The batch guide covers a whole folder.

Answers

Common questions

How do I rotate a MOV file on Windows?

Install ClipTurn from Microsoft Store, right-click the MOV in File Explorer, open the ClipTurn submenu and choose Rotate video left or Rotate video right. The stored picture is turned and saved into the same file, so it plays the right way up everywhere. Windows has no built-in rotate command for video files, and QuickTime for Windows has been unsupported since 2016.

Do I need QuickTime to rotate a MOV on Windows?

No, and you should not install it. Apple discontinued QuickTime for Windows in 2016 and stopped issuing security updates for it. Modern Windows plays MOV files without it, and a current rotation tool reads and writes the container directly.

Will rotating a MOV lose the date it was filmed or its GPS location?

It should not. The MP4 family route preserves the capture and media-created time, camera and GPS metadata, audio track language, colour declarations and display geometry, and verifies them against the source before the result is published. Many general-purpose converters do drop these and stamp the new file with today's date, which quietly ruins a library sorted by date taken.

Why is my iPhone Live Photo MOV refused?

A Live Photo MOV is paired with a separate still image, and rotating the video alone would break that pairing. It is refused deliberately and the source is left unchanged, rather than producing a video that no longer matches its photo. Rotating the pair properly has to happen on the device or in software that understands the pairing.

Can a MOV be rotated without losing any quality?

Yes, by rewriting the orientation instruction in the container rather than the picture. That is instant and completely lossless, but any player, editor or upload pipeline that ignores that instruction still shows the clip the old way. Physically turning the picture costs one encode generation and works everywhere.

Why does my iPhone MOV refuse with a missing HEVC codec message?

Recent iPhones record in HEVC, and Windows does not always include an HEVC encoder. Install a compatible HEVC Video Extensions package from Microsoft Store, which may be separately priced, then run the capability analysis again. An eligible 8-bit HEVC clip can instead fall back to H.264, and the result names that fallback rather than applying it silently. A 10-bit HEVC source is never quietly reduced to 8-bit.
