How to rotate a video on Windows 11 and Windows 10

The short answer: Windows cannot rotate a video from File Explorer on its own, but three routes get it done — Clipchamp, VLC, or a dedicated rotate command added to the right-click menu. Below is each one, what it costs you in quality, and how to make sure the turn is actually saved into the file rather than applied by the player.

The starting point

What Windows can do on its own

Less than most people expect, and the gap is the reason this question is asked so often.

Built into Windows Can it rotate video?
File Explorer right-click Photos yes, video no. Rotate left and Rotate right appear for JPEG and PNG images and never for video files.
Windows Media Player No. Neither the legacy player nor the newer Media Player app offers a rotation control. The full explanation is here.
Photos Rotates still images only. Video opens for playback and trimming, not rotation.
Clipchamp Yes. Included with Windows 11 and installable free on Windows 10. It rotates in a timeline and exports a new file. Covered below.

So the honest position is that Windows can rotate a video, but only by opening a video editor, placing the clip on a timeline and exporting a second file. For one clip that is a minor inconvenience. For twelve clips off a phone it is an afternoon.

Choose a route

Every method compared

Method Result Best for Watch out for
Right-click rotate Fastest The same file, turned and saved in place. Phone footage, several files at once, anything you want fixed and forgotten. Replaces the original, so keep a copy of irreplaceable footage.
Clipchamp A new exported file beside the original. One clip you were going to edit anyway. Re-encodes everything, and export settings decide the final quality.
VLC Playback looks correct; the file is unchanged until you also convert it. Checking which way a clip should turn before committing. The rotation is a playback filter. Most people stop here and think the job is done. Details.
Online rotators A downloaded copy, rotated. A single small clip on a machine where you cannot install anything. The video is uploaded to somebody else's server, and file-size limits and watermarks are common.
Two clips are not the same job as two hundred.

Every method above works for one file. The differences only start to matter at volume, when re-exporting each clip by hand stops being realistic and you need each file to succeed or fail on its own.

Method 1

The fastest method: rotate from the right-click menu

This adds the command Windows is missing — a rotate option on video files, in the same menu where you already rotate photos.

  1. Install ClipTurn and open it once

    Get it free from Microsoft Store, then launch it a single time so Windows registers its File Explorer commands.

  2. Select one or more videos

    The menu appears for .mp4, .m4v, .mov, .mkv, .avi, .wmv and .webm. If any file in the selection is a different type, the menu stays hidden.

  3. Choose the direction

    Right-click, open ClipTurn – Video Rotator, then pick Rotate video left or Rotate video right. With several files selected, the same direction is applied to each one independently.

  4. Read the result card

    A card reports each file as rotated, refused, failed or uncertain. A rotated file keeps its original name and location — the turn is now stored inside it, so every player agrees.

A right-click rotation replaces the original.

It is verified before anything is overwritten, but it does not leave a persistent backup and it cannot be undone from the app. To preview the turn first or keep a copy of the original, use Open in ClipTurn from the same menu and rotate inside the app with the backup setting turned on. The manual explains backups and recovery in full.

Method 2

Rotating in Clipchamp

Clipchamp ships with Windows 11 and installs free from Microsoft Store on Windows 10. It is a real video editor, so rotation is one operation among many: import the clip, drop it on the timeline, rotate it, then export.

  • The output is always a new file. Your original stays where it is, untouched.
  • Everything is re-encoded on export, including the audio, and the export settings you choose decide the final quality rather than the source file.
  • At the time of writing the free tier exports at up to 1080p, so a 4K clip comes back smaller than it went in.
  • It is a timeline editor, which makes it excellent for one clip you were going to trim anyway and slow for a folder of twenty.

If the clip needs trimming, captions or music as well as a turn, this is the right tool and the rotation is free along the way. If all it needs is a quarter turn, it is a lot of ceremony.

Method 3

Rotating in VLC

VLC's rotation lives under Tools → Effects and Filters → Video Effects → Geometry. Tick Transform, pick a rotation, and playback turns immediately.

That setting does not change the file.

It is a playback filter. Close VLC, open the video anywhere else, and it is sideways again — and because the filter is remembered, VLC keeps showing it correctly, which is why people are convinced it worked. Saving a rotated copy from VLC is possible but takes a specific and easily-missed sequence. The VLC guide walks through it.

Where VLC genuinely helps is deciding which way a clip needs to go. Toggling the transform during playback is the quickest way to see the answer before you commit to anything.

Get it right first time

Which way does it need to turn?

Rotating the wrong way and then rotating back costs you two generations of quality instead of one, so it is worth thirty seconds of checking.

What you see What it needs
The top of the scene is on the left Rotate right (clockwise) 90°
The top of the scene is on the right Rotate left (anticlockwise) 90°
Everything is upside down Rotate 180° — two quarter turns, saved once

For a 180° turn, do not save two separate 90° rotations. Each save is a fresh encode, so two saves cost twice the quality. In ClipTurn, click the direction button twice so the preview reads 180°, then save once. Batch Rotate offers Rotate 180° directly.

At volume

Rotating a whole folder

Selecting every file in File Explorer and using the rotate command once is enough for a handful of clips filmed the same way. Beyond that, or when the clips are mixed, the app's Batch Rotate tab is the better route.

  • Drop a folder onto the window to add every supported video directly inside it.
  • Each row keeps its own status and reason, so one file being refused never silently stops the others.
  • One direction applies to the whole run, which is exactly what you want for a batch of clips filmed the same way and wrong for a mixed bag.
  • Stop after the current videos ends the run gracefully; files already being processed finish rather than being killed mid-write.

The Batch Rotate section of the manual documents every status and the rules about when a row can safely be retried.

The honest trade-off

What rotation costs in quality

Any tool that physically turns compressed video has to decode it and encode it again. There is no way around that, and anyone claiming otherwise is either changing a display flag or not telling you.

  • One rotation is not a problem. A tool that targets the source bitrate produces a result you will not be able to tell apart from the original by eye.
  • Repeated rotations are. Each saved turn is another encode. Rotate, check, rotate back, rotate again and the losses stack up.
  • The rotated file may be larger. Preserving quality means not spending picture detail to hit the old file size. A bigger output is normal, not a bug.
  • MP4, M4V and MOV have a lossless option. Changing the display flag rather than the picture costs nothing at all — but some older players and editors ignore it. The MP4 guide covers the choice.

Uncompressed AVI is the one format where a quarter turn can be done with no loss whatsoever, because the stored pixels can simply be rearranged. Everything else involves a trade.

Before you delete the original

Checking the rotation actually saved

The most common bad outcome is not a corrupted file — it is believing a video was fixed when only the player was. Two quick checks settle it:

  1. Open it in a different program

    Not the one you rotated in. If you used VLC, check in Films & TV or a browser. A file that is genuinely rotated looks right everywhere.

  2. Check the dimensions swapped

    Right-click the file, open Properties → Details and read the frame width and height. After a genuine quarter turn a 1920×1080 clip reads 1080×1920. If the numbers are unchanged, the picture was not turned.

The dimension check has one exception.

A display-flag rotation deliberately leaves the stored dimensions alone and only changes how players are told to present them. That is the intended behaviour of that method, not a failure — but it is also why the flag is worth nothing to software that ignores it.

Answers

Common questions

Can Windows rotate a video without extra software?

Not from File Explorer. Windows can rotate a photo from the right-click menu, but there is no equivalent command for video. Windows 11 includes Clipchamp, which can rotate a clip and export a new file, and both versions of Windows can install a dedicated rotation app from Microsoft Store. Windows Media Player has no rotation feature at all.

How do I rotate a video 90 degrees on Windows?

Install ClipTurn from Microsoft Store, right-click the video in File Explorer, open the ClipTurn submenu and choose Rotate video left or Rotate video right. Each command turns the picture a quarter turn and saves the result into the same file. In the app itself, each click of Rotate left or Rotate right adds another 90°, so two clicks and one save produce a 180° turn.

Does rotating a video reduce its quality?

Rotating compressed video physically requires decoding and encoding it again, which costs one generation of quality. A good tool targets the source bitrate so the difference is not visible, but repeated saved rotations do accumulate. Rotating an MP4, M4V or MOV by changing its display flag instead is instant and lossless, but some older players and editors ignore that flag.

Why does my video look right on my phone but sideways on my PC?

The phone recorded the picture in one orientation and added a rotation flag telling players to turn it. Software that reads the flag shows the clip correctly; software that ignores it shows the raw stored picture, which is sideways. Physically rotating the stored picture removes the disagreement, because there is no longer a flag for anything to ignore. The sideways-video guide goes further into this.

How do I rotate several videos at once on Windows?

Select all of them in File Explorer and use the rotate command once — the direction is applied to each file independently. For a whole folder, or for a mix of files that need reviewing first, use ClipTurn's Batch Rotate tab, which lists every file with its own status and reason so one refusal does not stop the rest.
