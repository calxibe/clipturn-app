How to rotate a video in Windows Media Player

The honest answer first: you cannot. Windows Media Player has never had a rotation feature, and neither does the newer Media Player app in Windows 11. There is no hidden setting and no keyboard shortcut. What you can do is rotate the video somewhere else and then play it normally — this page covers both the two-minute fix and the watch-it-now workaround.

The short answer

Why there is no rotate button

Windows Media Player is a player. Rotating a video means writing a new video, and writing video was never part of its job.

Rotating a compressed clip means decoding every frame, turning it, and encoding it again into a new file. That is editing work. Windows Media Player reads files and draws them on screen; it has no encoder, no export and no save-as for video. The same is true of the Media Player app that replaced it in Windows 11, and of Films & TV.

Good news, such as it is.

Once the file itself is rotated, Windows Media Player plays it correctly with no configuration at all. It reads whatever orientation the file has. The fix just has to happen somewhere else first.

Worth knowing

Which player do you actually have?

Windows currently ships more than one thing called a media player, which is part of why this question gets confusing answers.

Application Where it comes from Can it rotate video?
Windows Media Player Legacy The classic player, still present on Windows 11 as an optional feature No
Media Player The newer Windows 11 app that replaced Groove Music No
Films & TV Bundled with Windows 10 and 11 No
Photos Bundled with Windows 10 and 11 Rotates images only, not video

So the answer is the same whichever one you are looking at. Nothing bundled with Windows rotates a video from a playback window.

The real fix

Fix the file in two minutes

Rotate the video itself, once, and every player — including Windows Media Player — shows it correctly from then on.

  1. Install ClipTurn from Microsoft Store

    It is free, needs no account, and runs entirely on your PC. Open it once after installing so Windows picks up its File Explorer commands.

  2. Right-click the video

    Open ClipTurn – Video Rotator and choose Rotate video left or Rotate video right. Works on .mp4, .m4v, .mov, .mkv, .avi, .wmv and .webm, and on several files at once.

  3. Play it in Windows Media Player as usual

    The rotation is now stored in the file, so nothing needs configuring in the player. The same file is also correct in browsers, editors, on a TV and on your phone.

A rotation replaces the original file.

The result is verified before anything is overwritten, but there is no undo. Keep a copy of footage you cannot replace, or use Open in ClipTurn from the same menu and turn on the backup setting so the original is kept alongside the result.

If you would rather not install anything, Windows 11 includes Clipchamp, which can rotate a clip on a timeline and export a new file. It is slower and re-encodes everything, but it is already there. Every method is compared here.

The workaround

Just watch it the right way up now

If you only need to get through this one clip and do not care about the file, use VLC as a viewer:

  1. Open the clip in VLC

    Then press Ctrl+E for Effects and Filters.

  2. Video Effects → Geometry

    Tick Transform and choose a rotation. Playback turns immediately.

  3. Remember to turn it off afterwards

    If you pressed Save, every video you open in VLC from now on is rotated too. Untick Transform when you are done.

This changes nothing about the file.

Windows Media Player will still show the clip sideways, because only VLC's display was rotated. The VLC guide explains the difference and how to export properly.

Save yourself the time

Workarounds that do not work

  • Rotating the screen with Ctrl+Alt+arrow. On graphics drivers that support it, this turns your entire desktop. It is occasionally suggested for this problem and it is a bad idea: everything else becomes unusable and the file is untouched.
  • Looking for a plugin or skin. Windows Media Player skins change the interface, not the video pipeline. No skin adds rotation.
  • Installing a codec pack. Codecs decide what can be decoded. Rotation is not a decoding problem, and codec packs commonly cause more playback trouble than they solve.
  • Renaming the file extension. This changes nothing inside the file and can stop it opening at all.

Answers

Common questions

Can Windows Media Player rotate a video?

No. Neither Windows Media Player Legacy nor the newer Media Player app included with Windows 11 has a rotation control, and no setting, shortcut or right-click option adds one. It is a playback application, not an editor. Rotating the video has to happen in a different program, after which Windows Media Player will play the corrected file normally.

Is there a keyboard shortcut to rotate a video in Windows Media Player?

There is not. Ctrl+Alt with an arrow key rotates your whole screen on some graphics drivers, which is occasionally suggested as a workaround, but it turns the entire desktop rather than the video and changes nothing about the file.

How do I watch a sideways video the right way up right now?

Open it in VLC, press Ctrl+E, go to Video Effects then Geometry, tick Transform and choose a rotation. Playback turns immediately. This changes only how VLC displays the clip, so the file stays sideways in every other program, including Windows Media Player.

How do I rotate the video file itself on Windows?

Install ClipTurn from Microsoft Store, right-click the video in File Explorer, open the ClipTurn submenu and choose Rotate video left or Rotate video right. The stored picture is turned and saved into the same file, so it plays correctly afterwards in Windows Media Player and everywhere else.

Why does Windows Media Player show my phone video sideways when my phone does not?

The phone stored the picture one way round and added a rotation flag describing how it was held. Software that reads the flag turns the picture for you; software that ignores it shows the stored picture, which looks sideways. Physically rotating the stored picture settles the disagreement for every player at once. More on sideways phone footage.
