What the outcomes mean

  • Verified replacementClipTurn rotated the video, verified it, then replaced the isolated test copy.
  • Lossless display copyClipTurn made a separate copy without re-encoding the video. The player must support rotation metadata.
  • Physical H.264 copyAfter approval, ClipTurn made a separate MP4 with physically rotated H.264 video.
  • Expected safe refusalClipTurn could not make a safe result, so it changed nothing.

Test method

How we tested the files

We ran every video through the Release x64 worker using a 90° right turn. The test checked the result, source hash and dates, output files, verification evidence, and temporary files.

When ClipTurn offered a reviewed copy, the test used its recommended choice. Other choices and output-name collisions are tested separately.

Separate automated tests cover left and 180° turns, queues, replacement, duplicate files, batch rotation, and the user interface.

Not tested here

  • ProRes 4444 XQ (ap4x) and ProRes RAW.
  • A full ARM64 media run. This 99-file run used x64.
  • Playback in Final Cut Pro, Premiere Pro, DaVinci Resolve, and every older player.
  • Every possible track, colour, timing, and metadata combination for each format.
