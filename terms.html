5. File replacement, backups, and recovery

ClipTurn is designed to verify a candidate before committing it, but a successful rotation normally replaces the selected file in place. Before using ClipTurn on irreplaceable media, keep an independent backup on separate storage.

  • File Explorer: a successful preserve-and-replace rotation keeps no persistent backup and cannot be undone through ClipTurn. If that path is refused, an explicitly approved alternative creates a separately named copy and leaves the source unchanged.
  • In-app workflow: keeping a backup is optional and off by default. A requested backup remains in your files until you remove it.
  • During commit: ClipTurn uses local staging and rollback material. It normally removes that material after completion, but may preserve recovery artifacts when automatic cleanup cannot safely finish.
  • Refusal or failure: when ClipTurn cannot produce and prove a safe result before commit, it is designed to leave the source unchanged and report a reason.

6. Technical limitations

A supported filename extension does not guarantee that every file with that extension can be rotated. Results depend on the file’s internal structure, codec, bit depth, metadata, stream layout, installed Windows codecs, hardware, drivers, available storage, and other device conditions.

  • Supported containers are MP4, M4V, MOV, MKV, WebM, WMV, and supported uncompressed AVI.
  • Only supported uncompressed packed-pixel AVI can be rotated sample-exactly.
  • Compressed video is physically rotated through a visually lossless re-encode under the default policy. Repeated re-encoding can accumulate loss.
  • The output can be larger because ClipTurn does not reduce quality merely to match the original byte size.
  • Codec availability varies. VP9 may require Microsoft’s free VP9 Video Extensions; HEVC may require Microsoft’s separately offered HEVC extension; Windows N may require Media Feature Pack; some 10-bit paths depend on hardware and drivers.
  • ClipTurn may refuse a file when it cannot preserve or verify a required property safely.
