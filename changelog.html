Changelog

Everything ClipTurn has shipped, newest first. Because ClipTurn is distributed through Microsoft Store, updates arrive the same way every other Store app updates — you do not download anything from this page.

Current version 1.0.1

v1.0.1

Latest August 2026

Fixed

  • An interrupted rotation could keep reporting failure — If a rotation was cut short at the exact moment your file was replaced, ClipTurn could go on reporting it as failed every time it started, even though the video had been rotated correctly. It now recognises the finished turn and reports it once.
  • Wrong colours in a few uncompressed AVI files — An AVI whose colour palette changes partway through could come back with the wrong colours from that point on. Those files are now refused by name, and the original is left untouched.
  • Two unusual AVI files failed slowly instead of refusing quickly — An AVI declaring a soundtrack that holds no audio, or declaring fixed-size video frames, used to be rotated in full and only then reported as failed. Both are now recognised before any work starts and refused with the reason.
  • A failed rotation could leave a spare copy of your video behind — A rotation that stopped partway could leave a name.backup-… file beside the original. Failed rotations now clean up after themselves.
  • One problem no longer stops the rest of a batch — A momentary problem writing ClipTurn's own progress record could halt the videos still queued behind it. The batch now carries on, and each file still reports its own outcome.
  • Dropping videos on Batch Rotate during a rotation — The list accepted the drop and then quietly ignored it. It now declines the drop visibly, the same way the Add videos button is unavailable while a rotation runs.
  • A damaged MKV file gave an unexpected error — A Matroska file whose structure cannot be read now gets ClipTurn's ordinary refusal saying it could not be inspected safely, instead of an error. An MKV carrying two separate sets of metadata tags is refused too, rather than quietly losing one of them.
  • Refusal messages name the right thing — An MKV could be refused with a message talking about a .webm file, and on a PC missing Windows' media support the refusal could name the wrong codec as the cause. A very long list of refusals is also no longer cut off in the result card.
  • A new install no longer looks stuck while opening — ClipTurn could finish its first-start check for unfinished rotations but leave Checking queued rotations... on screen. It now returns to No video selected and is immediately ready for you to choose a video.

v1.0.0

August 2026

Added

  • Rotate from File Explorer — Right-click a video and pick Rotate video left, Rotate video right or Open in ClipTurn. No export dialog, no second filename. Works with MP4, M4V, MOV, MKV, WebM, WMV and uncompressed AVI.
  • The video keeps its own codec — HEVC comes back as HEVC, VP9 as VP9, Windows Media Video in its own format. If your PC cannot write the original codec, the result says which one it used instead.
  • Exact rotation for uncompressed AVI — The stored pixels are moved rather than re-encoded, and a separate check confirms every one of them landed where the turn requires. Nothing is lost.
  • Your file is only replaced after an independent check — The rotated copy is decoded again and compared against the original: picture, sound, length, direction and colour. If anything fails, the copy is thrown away and your file is left untouched.
  • Safe to interrupt — A crash or power cut during a rotation cannot leave a half-written video behind. ClipTurn works out what happened on the next start instead of rotating the file twice.
  • The soundtrack is never re-encoded — In MKV, WebM and WMV files the audio is copied across untouched, so FLAC, ALAC, PCM, Dolby TrueHD, DTS-HD, Opus, Vorbis and MP3 all survive a rotation exactly as they were.
  • Subtitles, extra soundtracks and attachments survive — Text subtitle tracks, additional audio tracks, cover art and fonts are all carried across. Picture-based and styled subtitles are refused by name, because a quarter turn would leave their captions sideways or off-screen.
  • Capture date, location and HDR survive — The "Media created" date Explorer shows, GPS coordinates, camera make and model, track languages, colour information and 10-bit HDR all come through the rotation intact.
  • A better WebM encoder, built in — ClipTurn ships its own copy of libvpx 1.16 rather than relying on the ageing encoder Windows provides, so a rotated WebM is both smaller and sharper, and still seeks the way the original did.
  • System Capabilities — A plain report of what your particular PC can decode and encode. Where a missing piece has a free Microsoft download, it links there; where it does not, it says so instead of sending you somewhere that cannot help.
  • A receipt for every rotation — Each rotated file records what was checked, and Verify file again re-reads the file on disk to confirm it is still the video ClipTurn verified.
  • Uninstalling removes ClipTurn's data — Settings and job history go with the app; nothing is left behind in a folder you would have to find yourself.
Worth knowing before you rotate

Compressed video is re-encoded, so rotating the same file over and over slowly costs quality; only uncompressed AVI is exact. A rotation started from File Explorer replaces the file and cannot be undone. Some formats need codecs Windows does not include, and MPEG-1 and MPEG-2 are refused permanently because Windows cannot write them at all. The user manual explains each of these in full.

Updates arrive through Microsoft Store.

Install ClipTurn once and Windows keeps it current, the same as any other Store app.
